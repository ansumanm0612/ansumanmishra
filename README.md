# Ansuman Mishra — Academic Website

A responsive, static academic website built with HTML, CSS and vanilla JavaScript.

## Pages
- Home: introduction and guide to the site
- About me: academic background and interests
- Research & Projects: presentations, posters and research experience

## Site search
The magnifying-glass control in the top navigation opens a local search across the pages and the listed research activities.

## Publish with GitHub Pages
In the repository, open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select **main** and **/(root)**, then save.

The project repository URL is:
https://github.com/ansumanm0612/ansumanmishra

After GitHub Pages is enabled, the expected site URL is:
https://ansumanm0612.github.io/ansumanmishra/
